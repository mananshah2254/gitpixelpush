Privacy policy

Last updated: July 1, 2026

The short version

GitPixelPush is a static web page. It has no database, no user accounts of its own, no analytics, and no cookies. Everything it does happens in your browser, between you and GitHub. We could not sell your data even if we wanted to, because we never have it.

What we access on GitHub

When you sign in, GitHub asks you to grant two OAuth scopes:

  • read:user, used to read your public profile and your contribution calendar so the canvas can show your real graph.
  • public_repo, used to create one public repository that you name, and to push commits to it. GitPixelPush never reads, modifies, or deletes any other repository.

Your access token

  • The OAuth code is exchanged for a token by a small relay (a Cloudflare Worker), because that step requires an app secret. The relay passes the token straight back to your browser. It does not store it, log it, or attach it to any identity.
  • In your browser, the token is kept in sessionStorage. It is deleted when you close the tab or press Sign out.
  • All GitHub API calls, including every commit that paints your graph, are made directly from your browser to api.github.com.

What GitPixelPush creates

One public repository under your account, containing empty commits that are intentionally backdated to draw on your contribution graph. Each commit message is labeled gitpixelpush: pixel … and the repository README states that the content is contribution art. Deleting that repository removes every pixel from your graph.

Cookies and tracking

None. No cookies, no fingerprinting, no analytics scripts, no ads. Fonts are loaded from Google Fonts, which sees a standard font request from your browser.

Revoking access

You can revoke GitPixelPush's access at any time at github.com/settings/applications. Sign out in the app to clear the token from your browser immediately.

Changes

If this policy changes, the date above changes with it. Since the app is open in how it works, the source is the best documentation of what it does.
