Three steps, no install

01

Sign in

Authorize with GitHub. The public_repo scope permits access to public repositories; the tool uses it to write your chosen art repo. read:user reads profile information. Your token stays in this tab. Private canvases ask for GitHub's broader repo scope, and only if you choose that.

02

Paint

Your real graph becomes the canvas. Drag to draw, fill date ranges, stamp words in a pixel font, or drop a preset. Four ink levels, undo, and a live commit count as you go.

03

Push

Review the exact plan, then watch your browser create each backdated commit through the GitHub API and move the branch. Your graph updates within a minute or two.

Honest by design

  • It fabricates activity, and says so. The commits are empty, labeled gitpixelpush: pixel …, and the repo README states the graph art is intentional.
  • One repo, nothing else. GitPixelPush creates or reuses a single repository you name, public by default or private if you choose. It never touches your other repos, and deleting that repo erases every pixel.
  • No servers holding your data. This is a static page. Your token lives in this browser tab and dies with it. One tiny relay swaps the OAuth code for the token, stores nothing, and forgets you.
  • Undo anytime. Revoke access in GitHub settings, delete the repo, done.

Here is exactly what happens

  1. A public repository is created under your account.
  2. Your browser creates empty commits through the GitHub API, each backdated to its planned day and authored as .
  3. The main branch is moved to the newest commit. GitHub redraws your graph within a minute or two.

The repo README says it is contribution art made of backdated commits. Delete the repo and the pixels vanish. Pace is about one commit per second, the fastest GitHub allows for writes, so large plans take a while. You can stop anytime, progress sticks.

Private canvases need one extra GitHub permission (the repo scope, GitHub has no narrower one for creating private repos). And your pixels will only show if "Private contributions" is turned on in your profile's contribution settings on GitHub.
